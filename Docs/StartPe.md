# JsonDAP — آموزش

**JsonDAP** کتابخانه‌ی JSON و کار با فایل برای زبان D است: سریال‌سازی انواع خودتان، ویرایش فایل‌های
JSON با مسیر، و یک درخت استثنا که می‌گوید چه چیزی خراب بود.

- مرجع API: [README.fa.md](../README.fa.md) · تغییرات نسخه‌ها: [CHANGELOG.md](../CHANGELOG.md)
- برنامه‌ی مرجع: **TextDAP** در `JsonDAPtest/` — یک ویرایشگر متن متنی (کنسولی) که تمام وضعیتش در یک
  سند JSON زندگی می‌کند. هر فصل به همان خطی اشاره می‌کند که آن کار را آنجا انجام می‌دهد.

> برای نمایش درست این فایل‌ها، متن راست‌به‌چپ را در یک ویرایشگر یا مرورگر باز کنید؛ در ترمینالِ
> خام، ترتیب نمایش علائم ممکن است به‌هم بریزد. کدها و مسیرها همیشه چپ‌به‌راست‌اند.

## قواعدی که کتابخانه روی آن‌ها ساخته شده

1. **هیچ چیز بی‌صدا درست نمی‌شود.** فیلدِ نبود، مقدارِ enum ناشناخته و مسیرِ خراب، خطا هستند؛ نه
   مقدار پیش‌فرض، نه cast، نه حدس.
2. **هر `false` دلیلی دارد.** هر متد ویرایشی که `bool` می‌دهد، همتای `…WithMessage` هم دارد که همان
   دلیل را می‌گوید.
3. **`Optional!T` یعنی «مقداری نیست».** از 2.4.0 هیچ خواننده‌ای خطا داخل آن پنهان نمی‌کند.
4. **همه از `BaseExceptionAP` می‌آیند،** و همه فایل و خطِ جایِ raise را با خود حمل می‌کنند.
